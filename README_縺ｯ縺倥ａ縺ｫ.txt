ショコラ研究室（Chocolat Journal） v1.0
=======================================================

一粒に込められた、小さな世界。
二人で味わったボンボンショコラを、一粒ずつ記録するWebアプリです。

■ はじめに

「index.html」を開くとアプリが起動します。ただし、記録を安定して
保存するため、GitHub PagesなどのHTTPS環境で公開して使うことを
おすすめします。初回に一度読み込むと、オフラインでも利用できます。

【GitHub Pagesで公開する方法】
1. GitHubの新しいリポジトリを作成します（例：chocolat-journal）。
2. このZIPを展開し、中のファイルをすべてリポジトリの最上位に
   アップロードします。
   ※ index.html / app.js / styles.css / sw.js / manifest.webmanifest /
      iconsフォルダー / README が最上位に並ぶ構成です。
3. GitHubの「Settings」→「Pages」を開きます。
4. 「Build and deployment」→「Deploy from a branch」を選択し、
   mainブランチの /(root) を選んで「Save」します。
5. 公開されたURLをiPhoneのSafariで開きます。
6. Safariの共有ボタン →「ホーム画面に追加」を選ぶと、
   アプリのように起動できます。

■ 使い方

1. 「新しく記録」でショコラの名前とブランドを入力します。
2. 写真を選んで、円形に切り抜いて保存します。
   写真をドラッグして位置調整、ピンチ操作・スライダーで拡大できます。
   元写真も保存されるため、後から切り抜き直せます。
3. 味・香り・食感・見た目のタグを選択します。
4. 「わたし」「パートナー」を切り替え、それぞれ6項目の評価と
   テイスティングノートを入力します。
   評価 0 は「未評価」、1～10 が点数です。
5. 「この一粒を保存する」を押すと図鑑に追加されます。

「図鑑」ではブランド・味・香り・食感・見た目で検索できます。
「ブランド」ではショコラティエ → コレクション → 一粒の順に管理できます。
「好みの研究」では二人の平均評価をチャートやランキングで比較できます。
「設定」では二人の表示名を変更できます。

■ 保存とバックアップについて【重要】

このバージョンの保存先は、利用中のブラウザのIndexedDBです。
クラウド同期やログイン機能はありません。アプリの記録・写真が
自動的に他のスマートフォンへ転送されることもありません。

「設定」→「バックアップを保存」で、写真を含むすべての記録を
JSONファイルに書き出せます。機種変更前や定期的なバックアップに
ご利用ください。「復元」は統合・置き換えを選べます。

・端末のブラウザ履歴／サイトデータの削除で記録が消える場合があります。
・Safari版とホーム画面に追加した版は保存領域が異なる場合があります。
・写真が多い場合は端末の空き容量が必要です。
・iPhoneではバックアップを「ファイル」アプリへ保存してください。
・ウェブサイト（公開URL）を共有しても記録内容は共有されません。

■ 動作環境

iPhoneのSafari、Chrome、Edge等のモダンブラウザ。
オフライン対応にはHTTPSでの初回起動が必要です。

■ 今回のバージョンについて

実装済み：写真の円形トリミング、端末内保存、二人分の評価、
  テイスティングノート、4系統のタグ・絞り込み、ブランド／箱管理、
  お気に入り、レーダーチャート、JSONバックアップ、PWA。
未実装：Supabase同期、二人別々の端末での共同編集、AI分析。
